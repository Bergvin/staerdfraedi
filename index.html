Flatarmyndir – prófundirbúningur

Námsplan í sjö lotum, allar skilgreiningar og reglur sem þarf að kunna, sannanirnar skref fyrir skref, spjöld til að þjálfa sig og æfingadæmi með svörum. Hakaðu við jafnóðum, framvindan vistast í þessum vafra.

Námsplanið

Sjö lotur, hver um 45–60 mínútur. Best er að taka eina lotu á dag. Ef það eru færri dagar í prófið má sameina lotur 1+2 og 3+4. Lota 7 á að vera síðasti eða næstsíðasti dagurinn.

0 af 0 atriðum
Mikilvægast: Í prófi þarf oft að skrifa skilgreiningu eða sönnun orðrétt. Ekki bara lesa, heldur loka heftinu og skrifa á autt blað. Það sem ekki tekst fer aftur í bunkann.

Allar skilgreiningar og reglur

Allt innrammað efni í köflum 1, 2, 3 og 5, í sömu röð og í heftinu. Skáletruð hugtök þarf líka að kunna.

Sannanirnar

Fjórar sannanir sem hún þarf að geta skrifað sjálf. Smelltu á „Fela skrefin“, reyndu að skrifa sönnunina á blað og berðu svo saman.

Topphorn eru jafnstór

Sanna: x = z

  1. x og y eru grannhorn og því frændhorn: x + y = 180°
  2. y og z eru líka grannhorn og því frændhorn: y + z = 180°
  3. Báðar summurnar eru 180°, svo x = 180° − y = z ∎

Regla 1: Hornasumma þríhyrnings

Sanna: A + B + C = 180°

  1. Látum ΔABC vera gefinn. Drögum línu l gegnum B samsíða AC.
  2. Af frumreglu um einslæg horn leiðir x = A og y = C  (*)
  3. Línan l myndar 180° horn með oddpunkt B: x + B + y = 180°
  4. Setjum (*) inn: A + B + C = 180° ∎

Regla 2: Grannhorn við þríhyrning

Sanna: x = B + C, þar sem x er grannhorn hornsins A

  1. A og x eru frændhorn: A + x = 180°, þ.e. x = 180° − A  (*)
  2. Skv. reglunni um hornasummu þríhyrnings: A + B + C = 180°, þ.e. B + C = 180° − A  (**)
  3. Af (*) og (**) leiðir að x = B + C ∎

Regla 3: Pýþagóras

Sanna: Ef C = 90° þá er a² + b² = c²

  1. Drögum hæðina frá C á langhliðina c. Fótpunkturinn heitir D.
  2. ΔADC og ΔACB hafa sameiginlegt horn A og bæði rétt horn (við D og C). Þriðju hornin eru því líka jöfn (Regla 1), svo ΔADC ~ ΔACB
  3. Frumregla 2 gefur jöfn hlutföll: |AD| / b = b / c  ⇒  b² = c · |AD|
  4. Eins fæst ΔBDC ~ ΔBCA (sameiginlegt horn B og rétt horn): |DB| / a = a / c  ⇒  a² = c · |DB|
  5. Leggjum saman: a² + b² = c · (|AD| + |DB|) = c · c = c² ∎

Athugið: Í heftinu (bls. 15) stendur að sönnunin „bíði betri tíma“, svo hún er ekki þar. Þetta er algengasta sönnunin og byggir á kafla 3. Berið hana saman við sönnunina sem kennarinn sýndi í tíma og lærið þá útgáfu ef hún er önnur.

Spjöld

Lestu spurninguna, segðu svarið upphátt eða skrifaðu það, og snúðu svo spjaldinu. Spjöld sem fara í „Æfa meira“ koma aftur.

Æfingadæmi

Aukadæmi til viðbótar við æfingarnar í heftinu. Reiknaðu fyrst á blað og smelltu svo á dæmið til að sjá svarið.

Kvöldið fyrir og prófdagurinn

  1. Kvöldið áður: renna einu sinni yfir spjöldin, ekkert nýtt efni.
  2. Skrifa sannanirnar fjórar einu sinni á blað og fara svo að sofa.
  3. Taka með blýant, strokleður, reglustiku, gráðuboga og vasareikni ef leyfður.
  4. Í prófinu: teikna alltaf mynd og merkja hornin.
  5. Nefna regluna sem er notuð í hverju skrefi („skv. reglu 1…“).
  6. Byrja á dæmunum sem eru auðveldust og koma svo aftur að hinum.
  7. Í lokin: athuga hvort hornasumman í þríhyrningum sé 180°.
