Sannanirnar

Allar sannanir í heftinu sem enda á svörtum ferhyrningi ■, í sömu röð og í heftinu. Smelltu á „Fela skrefin“, skrifaðu sönnunina á blað og berðu svo saman. Í sviga aftast í línu stendur hvaða regla er notuð. Það er gott að venja sig á að skrifa það líka.

HR1.1 · Ef n er oddatala er n² oddatala bls. 26

  1. Gerum ráð fyrir að n sé oddatala, n = 2k + 1, þar sem k er heil tala.
  2. Þá fæst n² = (2k + 1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1 = 2m + 1
  3. sem er oddatala því að m = 2k² + 2k er heil tala. ■

HR1.2 · Ef n er heil tala og n² slétt er n slétt bls. 27

  1. Gerum ráð fyrir að n sé heil tala og n² slétt.
  2. Þá getur n ekki verið oddatala, því að þá væri n² líka oddatala skv. HR1.1.
  3. Því er n slétt tala. ■

Regla 1.5 · Jafnan x² = 2 hefur enga ræða lausn bls. 27

Þ.e. √2 er óræð tala. Sönnun með mótsögn.

  1. Gerum ráð fyrir að x² = 2 hafi ræða lausn og ritum hana sem fullstytt brot x = p/q, þar sem p og q eru heilar tölur og q ≠ 0.
  2. Þá er (p/q)² = 2, þ.e. p²/q² = 2, og þá p² = 2q²  (*)
  3. Þá er p² slétt tala svo að p er slétt skv. HR1.2. Þá er til heil tala k þannig að p = 2k.
  4. Af (*) leiðir 2q² = p² = (2k)² = 4k²  svo að  q² = 2k²
  5. Þá er q² slétt tala svo að q er slétt skv. HR1.2.
  6. Þá eru p og q báðar sléttar svo að stytta má brotið p/q með 2. En það stangast á við að brotið væri fullstytt.
  7. Forsendan um að x² = 2 hafi ræða lausn leiðir því til mótsagnar og fær ekki staðist. ■

Regla 1.6 · Að leysa einfaldar jöfnur þri bls. 31–32

1) a + b = c ⇔ a = c − b    2) Ef b ≠ 0: ab = c ⇔ a = c/b

  1. 1) Auðveldlega fæst: a + b = c ⇔ a + b + (−b) = c + (−b) ⇔ a + 0 = c − b ⇔ a = c − b
  2. 2) Ef b ≠ 0 fæst eins: ab = c ⇔ ab(1/b) = c(1/b) ⇔ a · 1 = c/b ⇔ a = c/b ■

Hugmyndin: leggja −b við báðar hliðar (andhverfa við samlagningu, F4), eða margfalda báðar hliðar með 1/b (andhverfa við margföldun, F4). Svo hlutleysureglan (F3).

HR1.3 · x² + bx + (b/2)² = (x + b/2)² þri bls. 37–38

  1. Skv. ferningsreglunni (a + b)² = a² + 2ab + b² fæst: (x + b/2)² = x² + 2 · x · (b/2) + (b/2)² = x² + bx + (b/2)² ■

Að bæta (b/2)² við x² + bx kallast að fylla ferninginn: hálfur stuðullinn við x er hafinn í 2. veldi og lagður við.

Regla 1.9 · Lausn 2. stigs jöfnu þri bls. 39–40

Ef A ≠ 0 hefur Ax² + Bx + C = 0 með greini D = B² − 4AC: tvær lausnir x = (−B ± √D)/(2A) ef D > 0, eina lausn x = −B/(2A) ef D = 0 og enga rauntölulausn ef D < 0.

  1. Þar eð A ≠ 0 má deila með A og færa C/A yfir: Ax² + Bx + C = 0 ⇔ x² + (B/A)x = −C/A
  2. Fyllum ferninginn (HR1.3), leggjum (B/(2A))² við báðar hliðar: x² + (B/A)x + (B/(2A))² = −C/A + (B/(2A))²
  3. ⇔ (x + B/(2A))² = −C/A + B²/(4A²)
  4. Setjum á samnefnara: ⇔ (x + B/(2A))² = (B² − 4AC)/(4A²) = D/(4A²)  (*)
  5. Þar sem 4A² > 0 hefur D/(4A²) sama formerki og D. Nú getur þrennt verið:
  6. D > 0: (*) ⇔ x + B/(2A) = ±√D/(2A) ⇔ x = −B/(2A) ± √D/(2A) ⇔ x = (−B ± √D)/(2A)
  7. D = 0: (*) ⇔ (x + B/(2A))² = 0 ⇔ x + B/(2A) = 0 ⇔ x = −B/(2A)
  8. D < 0: Þá er neikvæð tala hægra megin í (*) en jákvæð tala eða 0 vinstra megin. Jafnan fær þá ekki staðist og hefur enga rauntölulausn. ■

Regla 1.10 · Einfaldar ójöfnur Próf á þri bls. 46

Um öll a, b, c ∈ ℝ: 1) a > b ⇔ a + c > b + c   2) a > b ⇔ ac > bc ef c > 0   3) a > b ⇔ ac < bc ef c < 0

  1. 1) a + c > b + c ⇔ ((a + c) − (b + c)) ∈ ℝ₊  (skilgreining á >)⇔ (a − b) ∈ ℝ₊  (reiknireglur)⇔ a > b  (skilgreining á >)
  2. 2) a > b ⇔ (a − b) ∈ ℝ₊  (skilgreining á >)⇔ (a − b)c ∈ ℝ₊  (formerkjaregla, c ∈ ℝ₊)⇔ (ac − bc) ∈ ℝ₊  (dreifiregla)⇔ ac > bc  (skilgreining á >)
  3. 3) a > b ⇔ (a − b) ∈ ℝ₊  (skilgreining á >)⇔ (a − b)c ∈ ℝ₋  (formerkjaregla, c ∈ ℝ₋)⇔ (ac − bc) ∈ ℝ₋  (dreifiregla)⇔ ac < bc  (skilgreining á <) ■

Mikilvægasta afleiðingin: ójöfnumerki snýst við ef báðar hliðar eru margfaldaðar með neikvæðri tölu.

Regla 1.11 (1) · |t|² = t² bls. 53

  1. Skv. skilgreiningu tölugildis fæst strax:
  2. Ef t ≥ 0 er |t| = t, svo |t|² = t².
  3. Ef t < 0 er |t| = −t, svo |t|² = (−t)² = t²
  4. Í báðum tilvikum gildir |t|² = t². ■

Sannanirnar á liðum 2–5 í Reglu 1.11 eru á bls. 54, sem var ekki á myndunum. Kíkið á þær í heftinu.

Regla 1.12 · Að hefja í annað veldi bls. 57

Ef a ≥ 0 og b ≥ 0 gildir: 1) a = b ⇔ a² = b²   2) a > b ⇔ a² > b²

  1. 1) Gerum ráð fyrir að a ≥ 0 og b ≥ 0. Þar eð b ≥ 0 er √(b²) = b, svo a² = b² ⇔ a = ±√(b²) ⇔ a = ±b ⇔ a = b því að a ≥ 0 og b ≥ 0.
  2. 2) Gerum ráð fyrir að a > 0 og b ≥ 0. Þá er (a + b) ∈ ℝ₊ svo að Regla 1.10 gefur: a > b ⇔ (a − b) > 0 ⇔ (a − b)(a + b) > 0 · (a + b)⇔ a² − b² > 0 ⇔ a² > b² ■

Aukalega · Æfing 1.3.2: a > b ∧ b > c ⇒ a > c bls. 25

Heftið segir að nemendur eigi að sanna þetta sjálf. Svona má gera það:

  1. a > b þýðir (a − b) ∈ ℝ₊ og b > c þýðir (b − c) ∈ ℝ₊  (skilgreining á >)
  2. Summa jákvæðra talna er jákvæð (formerkjaregla), svo (a − b) + (b − c) ∈ ℝ₊
  3. En (a − b) + (b − c) = a − c  (reiknireglur), svo (a − c) ∈ ℝ₊, þ.e. a > c. ■
